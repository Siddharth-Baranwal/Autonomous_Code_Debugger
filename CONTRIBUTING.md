# Contributing

Thanks for your interest in this project.

## Development setup

1. Create and activate a virtual environment.
2. Install dependencies with `uv sync` or `python -m pip install -e .`.
3. Run tests with `uv run python -m unittest tests.test_dashboard tests.test_pipeline tests.test_reporting`.

## Pull requests

- Keep changes focused.
- Update documentation when behavior changes.
- Verify tests before opening a PR.
